# LLM Benchmarking

Record the environment with every benchmark:

```text
Model:
Runtime:
Version:
Quantization:
Hardware:
Context:
Concurrency:
Duration:
```

Test cold start, warm requests, concurrent requests, sustained throughput, resource utilization, and failure/recovery behavior.

Where supported, record time to first token, tokens per second, total latency, CPU, RAM, GPU, and VRAM.
